# Landing Page - Desfile del 9 de Octubre

## Objetivo del Proyecto
Desarrollo de la primera versión funcional de una landing page para organizar y presentar la información recopilada sobre el Desfile cívico-estudiantil del 9 de Octubre en Guayaquil. Este proyecto aplica prácticas de planificación ágil, selección de plantillas y control de versiones

## Sobre el Evento
El desfile es una actividad que fortalece el sentido de identidad, civismo y tradición guayaquileña, involucrando a estudiantes, bandas musicales, familias y comerciantes locales en los alrededores del Parque La Victoria

## Estructura del Sitio
El contenido de la página web está organizado en las siguientes secciones principales:
1. Inicio (Información general)
2. Sobre el Desfile (Contexto cultural)
3. Participantes (Grupos involucrados)
4. Impacto y Comunidad (Análisis ciudadano)
5. Visión a Futuro (Sugerencias y mejoras)

## Tecnologías Utilizadas
* HTML5 y CSS3
* Plantilla base: [Nombre de la plantilla elegida, ej. Stellar] de HTML5 UP.
* Control de versiones: Git y GitHub.
